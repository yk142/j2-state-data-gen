# 要件定義書 — C8-A901S J2 単軸 Neural State Model 学習データ生成

- 文書バージョン: 0.1（初版・ドラフト）
- 作成日: 2026-10-06
- 対象: **EPSON C8-A901S の J2（肩ピッチ軸）**。他軸を固定した J2 単軸モデル
- 実装基盤: MATLAB / Simulink / Simscape Multibody
- 真値の出典: `~/matlab-projects/robotArmSurrogate-matlab`（以下「親資産」）。**path 参照のみでコピーしない**
- 元資料: 引継ぎ資料（`Neural State Model 学習データ生成スクリプト 引継ぎ資料…md`）。ただし `simulate_joint2` と Python + matlab.engine 構成は仮のもので不採用

---

## 1. 目的

J2 の次時刻状態推論モデル（Neural State Model）を学習するためのデータを、Simscape の真値プラントから生成する。

- 入力: 現在状態 `(θ, θ̇)` ＋ トルク `τ`
- 出力: 次時刻状態 `(θ_{t+1}, θ̇_{t+1})`
- 狙い: 状態空間全域（倒立点近傍・重力支配域・リミット近傍・高トルク域）の動力学カバレッジ

## 3. 制約

- **使用禁止 Toolbox**: Deep Learning、System Identification、Statistics and Machine Learning
- Simulink / Simscape Multibody を基本とする
- 親資産は参照専用（コピー・改変しない）。必要な処理はこのリポジトリ側に実装する
- 再現性: 乱数シード固定、生成条件をマニフェストに記録
- 日本語でコメント・文書を記述
- Parallel Computing Toolbox は未許諾（`parsim`/`parfor` は使えない）。8 kHz シミュレーションは直列実行を前提とする

## 4. 機能要件

### FR-1 J2 単軸プラント
- 親資産の `buildC8Plant` で生成した 6 軸 URDF/モデルを入力とし、**J1, J3〜J6 を固定した J2 のみ可動のプラント**を構築する
- 固定姿勢は **J1, J4〜J6 = 0、J3 = 75.0684°**（`config/j2_config.m` の `qFixed`）。J3=0（L 字姿勢）では J2 の重力平衡点が θ≈+11° にずれるため、θ=0 を倒立平衡点にする J3 を `c8RNEA` の `fzero` で求めた。この姿勢で J2 の重力トルクは厳密に `−mgL·sin θ`（mgL=73.25 N·m）になる（[phase0_report.md](phase0_report.md)）
- I/F: `Inport tau`（スカラ、N·m）→ `Outport q, dq`（スカラ、rad, rad/s）
- J2 の armature・摩擦は親資産の値を使う（固定軸の armature・摩擦は不要）
- 固定の実現方法は **方式 A（生成 URDF の該当 joint を `fixed` に後処理して `smimport`）に決定**（Phase 0。方式 B の高剛性保持と J2 応答が 0.001° 以内で一致し、実行は約 3〜5 倍速い）

### FR-2 物理妥当性の検証
- θ=0 が倒立位置（不安定平衡）か、重力トルクの符号と大きさが想定どおりか
- 自由落下がリミットに到達するか（安定点 −180° は範囲外）
- 重力トルクを `c8RNEA`（親資産）の J2 成分と比較し、固定姿勢での整合を確認

### FR-3 リミットとソフトバリア
- Simscape の URDF 由来リミットはソフトリミット（減衰あり）で、接触すると約 0.3° めり込んで静止する（Phase 0 実測）。重力が両側ともリミット方向に働くため、**自由落下や押し付けでは、リミットに張り付いたまま動かない**
- 開ループ励振には親資産と同様のソフトバリア（位置・速度の安全帯＋トルク飽和 `tauPeak`）を入れる。安全帯は `setJ2Barrier` で実行前に変更できる（既定: 位置 0.85、速度 0.60）
- **リミット拘束サンプル**（リミットから 0.1° 以内または外側）は、生データには残し、割合を `raw.contact` で返す。データセット（Phase 3）でフラグを付け、**既定では学習用フラットデータから除外する**（実機の機械ストッパの挙動を表していないため。含める場合は明示的に指定）
- リミット近傍のカバレッジは、閉ループ保持（参照をリミットの 4° 内側）の `nearlimit` シナリオで取る
- **結果（Phase 3、full）**: 励振モデルのバリアは自由落下にも効くため、データはリミットに一度も接触しない（リミットから 1° 以内は 127 サンプル）。リミット拘束フラグは実質無効（0%）で、機械ストッパの挙動は学習対象外。含める場合はバリアを外した接触シナリオを別 issue で追加する

### FR-4 励振シナリオ
引継ぎ資料の収集計画を踏襲し、実値で再計算する。

- フェーズ1（広域）: バンドリミテッドノイズ（通常・高トルク・低速）、自由落下。初期状態は Sobol 列
- フェーズ2（構造的）: 重要 7 姿勢（0, +30, +60, −45, −90, −120, −150°）× 各複数軌跡、チャープ、最大トルクステップ、微小トルク、リミット近傍
- フェーズ3（能動学習補完）: **スコープ外とし後続 issue で扱う**（学習側が必要。Deep Learning Toolbox 禁止のため手書き NN が前提）
- 倒立点近傍は自由落下では通過するだけなので、安定化制御＋外乱で収集する
- トルク振幅は `tauPeak(2)=860 N·m` を基準に定義する（資料の「0.5 τ_max」等は要再定義）

### FR-5 サンプリング
- シミュレーション 8 kHz、学習データ 1 kHz（Δt=1 ms、1/8 間引き）
- 8 kHz 生データは保存してから間引く
- 間引きは親資産の `c8Downsample`（アンチエイリアス付き）を使うか、同等の処理を実装する。**単純間引きは使わない**
- 1 kHz の J2 単軸に対し、親資産の 200 Hz は別系統であり混同しない

### FR-6 データセット
- シナリオ単位でキャッシュし、中断しても再開できる（`genC8Dataset` の流儀）
- train/val/test はシナリオ単位で分割し、正規化統計は train のみから算出（リーク防止）
- マニフェスト（生成条件・シード・パラメータ出典・固定姿勢）を保存
- 保存形式は `.mat`（`-v7.3`）。HDF5 は不要（MATLAB 完結のため）

### FR-7 入出力表現（要決定）
- 資料案: 入力 `(sin θ, cos θ, θ̇/DTHETA_MAX, τ/TAU_MAX)`、出力は差分残差
- J2 の範囲（223°）は 2π 未満で折り返しがない。θ をそのまま入力にする案と sin/cos 案を比較する
- 本 issue ではデータ生成までを対象とし、表現は学習側で選べるよう θ, θ̇, τ を生のまま保存する

### FR-4b PTP 連続 GO 動作（ベンチマーク軌道）
- 初期座標から目標座標への **PTP 制御の GO 動作を連続して実行**した軌道を、ベンチマークとして生成する（親資産の `tracking` シナリオ、`c8TrajGen` / `c8TrajSegTime` / `c8TrajAddDwell` / `c8FeedForward` の流儀）
- J2 単軸の閉ループ（サーボ制御器＋FF トルク）で実行する。制御器は親資産 `c8GainDesign` を参考に J2 用に構成する
- ウェイポイントは J2 の訓練範囲内（可動域の ±70%、`qTrainMin/Max`）からシードで生成。複数ウェイポイントを連続で巡り、停止時間（dwell）を挟む
- 速度スケールを変えた複数本を用意し、励振系（FR-4）との差（動作域の偏り）を評価で比較できるようにする
- ベンチマーク軌道は `phase = benchmark` として別 split／別ラベルで保存する

### FR-8 カバレッジ評価
データセット（および励振系・ベンチマーク別）に対して以下を出力する。全て PNG で保存する。

1. **時系列プロット**: 角度 θ、角速度 θ̇、トルク τ の時系列（代表軌跡ごと、3 段構成）
2. **位相平面プロット（3 種）**: θ–θ̇、θ–τ、θ̇–τ。可動範囲・倒立点（θ=0）・θ̇/τ の上限を重ねる。点数が多いため密度（2 次元ヒストグラム）表示を基本とする
3. **周波数カバレッジ評価**: τ と θ̇ の PSD（シナリオ別と全体）、および軌跡ごとのスペクトログラム。励振帯域（〜20 Hz）に対する実カバー帯域を示す。実装は MATLAB の `pwelch` / `spectrogram`（Signal Processing Toolbox）。**この環境でライセンス checkout と実行を確認済み**（2026-10-06）。
   - **フォールバック**: Signal Processing Toolbox が使えない環境では、周波数評価のみ Python（numpy / scipy.signal / matplotlib）で実施してよい。その場合、MATLAB 側は生データを `.mat`（`-v7`）または CSV で書き出し、Python 側は同じ PNG 出力仕様（ファイル名・図の構成）に合わせる。この環境の system python には scipy が未導入なので、必要になった時点で venv を作る
   - 時系列・位相平面は基本 MATLAB の標準プロットのみで実現し、Toolbox 依存を作らない
4. 数値指標: (θ, θ̇, τ) 3 次元占有率、各 2 次元平面の占有率、帯域別パワーの最小値

### FR-9 評価結果の報告（issue コメント）
- カバレッジ評価の PNG は `reports/issue-<N>/` に保存し、ユーザー指示によるコミット後、**コミット SHA 固定の raw URL** で issue コメントに `![](...)` として埋め込む（ブランチ削除後も表示を維持するため）
- コメントには数値指標の表と、生成条件（シード、固定姿勢、親資産のコミット）を併記する

## 5. 非機能要件

- NFR-1 再現性: 同一設定で同一データ
- NFR-2 実行時間: 8 kHz 真値は 1 シナリオ約 100 s。単軸化で短縮されるかを Phase 0 で実測し、総所要時間を見積もる
- NFR-3 試験: `matlab.unittest` で各関数の単体テスト
- NFR-4 親資産への依存を `addpath` 一箇所に集約し、パスの設定を設定ファイルで管理

## 6. 成功基準

1. J2 単軸プラントが 8 kHz で数値的に安定して動く（発散・NaN なし）
2. FR-2 の物理妥当性チェックがすべて通る
3. 全シナリオから 1 kHz データセットが生成され、検証関数がエラー 0
4. カバレッジの目標値を達成（Phase 3 で決定、2026-10-06 承認）。到達不能なセルがあるため、PTP ベンチマークの被覆を主指標とする:
   - PTP ベンチマークの遷移が学習系の占有セルに入る割合: 3 次元 90% 以上、2 次元（各平面）95% 以上（20 ビン格子）
   - 2 次元占有率: 各平面 60% 以上
   - τ の周波数被覆: 0.5〜20 Hz でピークから −30 dB 以内

## 7. 未決事項・リスク

| # | 内容 | 対応 |
|---|---|---|
| 1 | 固定軸の実現方法（URDF 後処理 vs 剛性保持） | **解決**: 方式 A に決定（Phase 0） |
| 2 | θ=0 が倒立平衡か | **解決**: J3=75.0684° 固定で θ=0 が不安定平衡、重力トルクは −mgL·sin θ に一致（Phase 0） |
| 2b | θ=0 近傍の自由落下 | クーロン摩擦（23.8 N·m）が重力トルク（73.25·sin θ）を上回る約 ±19° 以内ではほぼ動かない。この領域は自由落下では取れないため、トルク励振が必須（FR-4） |
| 3 | リミット接触時のサンプルの扱い（除外／含める） | 挙動は観察済み（ソフトリミット、約 0.3° めり込み・減衰して静止）。扱いは Phase 2 で決定 |
| 4 | `tauPeak`＝定格×3 は推定値 | データ妥当性チェックで感度を確認 |
| 5 | 8 kHz 実行時間 | 方式 A で実時間の約 5〜6 倍。3.4M サンプル（3,400 s）で約 5〜6 時間の見込み |
| 6 | 固定姿勢が 1 つだけだと J3 依存の汎化は取れない | 1 姿勢（J3=75.0684°）で進める。拡張は後続 |
| 7 | 引継ぎ資料のフェーズ3（能動学習）の扱い | 後続 issue |
