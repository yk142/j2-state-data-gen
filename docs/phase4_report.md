# Phase 4 レポート — 再現確認とドキュメント整備（issue #13）

実施日: 2026-10-06 / MATLAB R2025a

## 4.1 再現確認
### 8 kHz 生データの再生成（キャッシュなし、別プロセス）
`tools/j2_repro_check.m` を、新しい MATLAB プロセス（`matlab -batch`）で実行した。モデルを一時フォルダで作り直し、種別ごとの代表 10 シナリオをキャッシュを使わずに再生成して、保存済みの 8 kHz 生データ（single）と比較した。

| シナリオ | 種別 | サンプル数 | max\|Δq\| / \|Δdq\| / \|Δτ\| | 判定 |
|---|---|---|---|---|
| bln_high_001 | 励振 | 40,001 | 0 / 0 / 0 | ビット一致 |
| freefall_001 | 励振 | 24,001 | 0 / 0 / 0 | ビット一致 |
| step_001 | 励振 | 16,001 | 0 / 0 / 0 | ビット一致 |
| micro_001 | 励振 | 80,001 | 0 / 0 / 0 | ビット一致 |
| hold_-090_001 | 姿勢保持 | 40,001 | 0 / 0 / 0 | ビット一致 |
| nearlimit_001 | リミット近傍 | 80,001 | 0 / 0 / 0 | ビット一致 |
| ptp_v40_001 | PTP | 41,346 | 0 / 0 / 0 | ビット一致 |
| contact_fall_001 | 接触 | 24,001 | 0 / 0 / 0 | ビット一致 |
| contact_drive_001 | 接触 | 32,001 | 0 / 0 / 0 | ビット一致 |
| contact_bln_001 | 接触 | 80,001 | 0 / 0 / 0 | ビット一致 |

**10 本中 10 本がビット一致**。保存済みデータは別のプロセス・別の時刻（Phase 3 の 2 本のワーカーと #11 の追加生成）で作ったもので、セッションの状態にも依存しない。結果は `reports/issue-13/repro.json`。

### 1 kHz データセットの組み立て
`genJ2Dataset` を `save=false` で再実行して（キャッシュから 8 kHz → 1 kHz、統計、split、フラグを組み立て直し）、保存済みの `data/j2_dataset_full.mat` と比較した。**394 本・全 13 フィールドの差分 0 件、`stats` と `scale` も一致**。

### 再現の条件
- 乱数はすべてシナリオごとのシード（`seedBase = 20261006` からの決定的な割り当て）
- 同じ MATLAB R2025a、同じ親資産のコミット（`5a7c690`、manifest に記録）
- 他の環境（別バージョンの MATLAB/Simscape）でのビット一致は未確認

## 4.3 後続課題（issue 化）
| issue | 優先度 | 内容 |
|---|---|---|
| #14 | 高 | バリア内部での大トルク励振と step のバリア振動の抑制（θ–τ の偏り是正） |
| #15 | 高 | データセットの他言語向けエクスポート（HDF5 / npz 等） |
| #16 | 中 | 動的なリミット接触の増強 |
| #17 | 中 | 静止押し付け遷移（接触の 93.6%）の重み・間引きオプション |
| #18 | 低 | 生成の高速化（Simscape コンパイルのオーバーヘッド削減） |
| #19 | 低 | J3 固定姿勢のバリエーション、または J3 を入力に加えた拡張 |
| #20 | 低 | フェーズ 3（能動学習補完）— 学習側の実装が前提 |

優先度の根拠: #14 は学習結果（大トルクとバリアの相関の誤学習）に直結する。#15 は MATLAB 以外の学習側で使えるかを左右する。#16・#17 は接触データの質、#18〜#20 は規模・拡張の課題で、現状のデータで学習を始めることはできる。
